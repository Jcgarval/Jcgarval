## Proyectos destacados

### [BarberFlow](https://github.com/Jcgarval/BarberFlow) · API REST
API para gestionar citas, barberos y servicios de una barbería: autenticación JWT con roles, cálculo de horas libres según la duración del servicio, control de solapes, estados de cita y baja lógica para conservar el historial. Más de 80 pruebas automáticas (cobertura del 95 %) que se ejecutan en GitHub Actions.
